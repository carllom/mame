# Roland S-330 RC-100 Controller Reference

## Overview

The RC-100 is an external remote controller for the Roland S-330 sampler. It connects via serial link and provides a keypad, dial, and passthrough ports for a mouse (MU-1) or digitizer tablet (DT-100). Communication is bidirectional with negated serial data in both hardware and software.

## Hardware

### CPU & Memory

- **CPU:** Intel 80C31 (8051 family)
- **ROM:** 27C128 — 16KB, 14 address lines
  - `/CE = A14` → mapped at 0000-3FFF and (mirrored) 8000-BFFF
- **Gate Array:** M60003A-0117SP
  - D0-D7 data bus
  - A13-A15 → A2-A0 (note reversed bit order)

### Internal RAM Map

| Address   | Description                              |
|-----------|------------------------------------------|
| 00-1F     | 3 register banks × 8 registers (R0-R7)  |
| 20-2F     | Bit-addressable RAM (addresses 00h-7Fh)  |
| 30-6E     | Scratch RAM / variables                  |
| 6F+       | Stack                                    |

### Key Variables

| Address | Value | Description          |
|---------|-------|----------------------|
| 30      | 60h   |                      |
| 31      | 60h   |                      |
| 32      | 68h   |                      |
| 33      | 68h   |                      |
| 37      | FFh   |                      |

### Key Scan

- Write FFh to $A000 to scan keys
- Read $A000 × 4 times
- XOR with R0 to detect changes (any change bit = 1)

## External Device Port Pinout

The RC-100 has a connector for external devices (mouse, digitizer tablet, or "device 3"):

| Pin | Signal | RC-100  | MU-1 Mouse | DT-100 Tablet | Device 3       |
|-----|--------|---------|------------|---------------|----------------|
| 1   | MX0    | DATA1   | D0         | /SENSE        | /BSY (0=busy)  |
| 2   | MX1    | /ATN    | D1         | EOC           | GND            |
| 3   | MX2    | GND     | D2         | SO            | GND            |
| 4   | MX3    | GND     | D3         | /SW           | GND            |
| 5   | +5V    | +5V     | +5V        | +5V           | +5V            |
| 6   | MX4    | CLK1    | LMB        | /SCK          | /EXEC          |
| 7   | MX5    | CLK2    | RMB        | SI            | CLK            |
| 8   | MX6    | DATA2   | STRB       | /CS           | DATA           |
| 9   | GND    | GND     | GND        | GND           | GND            |

### Device Identification

- **Device 3** is identified by having pins 2-4 (MX1-MX3) grounded
- **DT-100** (Roland digitizer tablet) is compatible with the Philips NMS-1150 Graphic Tablet
  - Uses a uPD7001 A/D converter for coordinate digitization
  - INT1 is driven by external clock on MX4/MX5

## Serial Protocol: RC-100 → Host (S-330)

Commands sent from the RC-100 to the S-330:

| Byte(s)        | Command      | Description                                        |
|----------------|--------------|----------------------------------------------------|
| 00-25          | KeyOn        | Key press (see key code table below)               |
| 30-33          | JmpTrg 0-3  | External device trigger (jmptrg0=3)                |
| 34             | ReadBlock    | Request to read 128-byte block (device 3 only)     |
| 35 dd×128      | WriteBlock   | Write 128-byte data block (device 3 only)          |
| 36             | (unknown)    |                                                    |
| 37 dd          | ExtData      | Data byte from external device port                |
| 40-65          | KeyOff       | Key release (key code + 40h)                       |
| 80 nn          | Dial         | Dial value                                         |
| C0 xx yy       | Mouse        | Mouse coordinate passthrough                       |

### Byte Format

```
11000000 = C0 XX YY  — Mouse passthrough
10000000 = 80 NN     — Dial value
0011XXXX = 3X        — Reset (all control values off)
01XXXXXX = XX        — Key press (code = byte & 3F)
00XXXXXX = XX        — Key release (code = byte & 3F)
```

## Serial Protocol: Host (S-330) → RC-100

Commands sent from the S-330 to the RC-100:

| Byte(s)       | Command     | Description                                         |
|---------------|-------------|-----------------------------------------------------|
| 80             | Identify    | Identify/select external device                    |
| 81             | CheckInput  | Check dial + keys (jmptrg 0/3)                    |
| 82             | ExecFunc    | Execute function for selected external device      |
| 83             | WriteBlock  | Write 128-byte block to ext device (see below)     |
| 84             | ReadBlock   | Read 128-byte block from ext device (see below)    |
| 85             | ReadExt     | Read from ext port (RC-100 answers with cmd 37 dd) |
| 86 XX          | WriteExt    | Write-through data byte to ext port                |
| aa bb cc dd    | SetLEDs     | Set LED state on RC-100 panel                      |

### Command 83: Write Block (Host → Ext Device via RC-100)

Writes 128 bytes (64 word pairs) to the external device through the RC-100:

```
Host         RC-100       Ext Device
|---83------>|             |
|            |---20------->|
|            |---30------->|
|<---34------|             |
|---aa------>|             |           ─┐
|---bb------>|             |            │
|            |---40------->|            │ repeated 64 times
|            |---aa------->|            │
|            |---bb------->|            │
|            |             |           ─┘
|            |---00------->|
```

### Command 84: Read Block (Host ← Ext Device via RC-100)

Reads 128 bytes from the external device through the RC-100:

```
Host         RC-100       Ext Device
|---84------>|             |
|            |---80------->|
|            |<---aa-------|
|            |<---bb-------|
|<---35------|             |
|<---aa------|             |
|<---bb------|             |
|            |---81------->|
|            |<---cc-------|
|            |<---dd-------|
|<---cc------|             |
|<---dd------|             |
|            |---82------->|
|            |<---cc-------|
|            |<---dd-------|
|<---cc------|             |
|<---dd------|             |
|            | ... continues incrementing command byte ... |
|            |---BF------->|
|            |<---cc-------|
|            |<---dd-------|
|<---cc------|             |
|<---dd------|             |
```

### Mode Key Mapping

Keys 88h-8Dh (PLAY through UTIL) map to mode indices 0-5, stored in the S-330's mode register (EA/D2). Keys 1Bh-1Eh (COMMAND through EXECUTE) are sub-mode navigation keys. The mode key mapping at address B1.F82:

```
1B, 1C, 1D, 1E, 88, 89, 8A, 8B, 8C, 8D
```

- 88h-8Dh → stored in register EA (mode 0-5), connected to $667B-6680
- 1Bh-1Eh → sub-mode navigation

## DT-100 State Machine

The DT-100 tablet uses a 10-state machine for tracking touch/release:

```
S0 (615h):
    bit 24.6 = 0 → stay S0
    bit 24.6 = 1 → [init] → S1

S1 (635h):
    bit 24.6 = 0 → S2
    bit 24.6 = 1 → [acc_queue] → S1

S2-S8 (6C5h):
    bit 24.6 = 0 → S[n+1]
    bit 24.6 = 1 → S1

S9 (6CBh):
    bit 24.6 = 0 → S0
    bit 24.6 = 1 → S1
```

- **S1** is the active touch state — executes while the pad is touched
- **S2-S9** provide a timeout after touch release (debounce/cooldown)
- After the full timeout (S2→S9 without re-touch), returns to idle (S0)
